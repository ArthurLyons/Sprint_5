# Автотесты для Stellar Burgers

Автоматизированные тесты для веб‑приложения Stellar Burgers с использованием Selenium WebDriver.

## Функциональность

Тесты покрывают:
* регистрацию пользователей;
* авторизацию разными способами;
* навигацию по сайту;
* работу с конструктором бургеров.

## Структура проекта

* `tests/` — все тестовые файлы;
* `conftest.py` — фикстуры и общие настройки;
* `utils/generators.py` — вспомогательные генераторы данных.

## Требования

* Python 3.8+;
* Selenium;
* WebDriver для Chrome/Firefox.

## Запуск тестов

1. Установите зависимости: `pip install -r requirements.txt`.
2. Запустите тесты: `pytest tests/`.
